# Palm Heat Cover Studio

A GTA 6 cover-art studio in the browser — design a GTA VI-style game cover with a sunset hero, six multi-panel layouts, four grades, and a live editor, then export it as PNG.

## What it does

- Six multi-panel cover layouts, four grades (gradient-map and poster-ink)
- Live editor: crop and move every panel, undo/redo
- Sunset hero with Anton title and Pacifico script subtitle
- PNG export at 1920x1080, 1080x1350, and 1080x1080
- Offline, plain Node 22, zero dependencies; Anton and Pacifico ship as files with eight sample photos

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080.
