# Palm Heat Cover Studio — turn your photos into a GTA 6 cover

Pick a sunset hero shot, lay it out across six multi-panel cover
designs, wash one of four grades over the whole thing, drag every
panel until it sits exactly where you want it — then save the
finished cover as a PNG. It all runs in the browser; nothing is
ever uploaded anywhere.

## What you get

- Six multi-panel cover designs, plus four grades — gradient-map looks and a poster-ink treatment
- A live editor: crop and shift any panel, with undo and redo
- A sunset hero photo under an Anton title and a Pacifico script subtitle
- PNG exports at 1920x1080, 1080x1350 and 1080x1080
- Fully offline, plain Node 22, no dependencies at all; Anton and Pacifico ship as files, along with eight sample photos

## Running it

```sh
node serve.ts # start the studio
```

Once it is up, open http://localhost:8080 in a browser.
