# Palm Heat — GTA 6 Cover Studio

Build your own GTA VI-style game cover in the browser: a burning-sunset hero shot, six multi-panel layouts, four colour grades, and a live editor you can drag around — then export the finished cover as a PNG.

## What you get

- Six multi-panel cover layouts, plus four grades (gradient-map looks and a poster-ink treatment)
- A live editor: crop and move every panel, with undo/redo
- A sunset hero photo under an Anton title and a Pacifico script subtitle
- PNG exports at 1920x1080, 1080x1350, and 1080x1080
- Fully offline, plain Node 22, no dependencies; Anton and Pacifico are bundled as files, along with eight sample photos

## How to run it

```sh
node serve.ts # start the studio
```

Then open http://localhost:8080 in your browser.
